# Screenshots

Drop the website screenshots referenced by the main [README](../../README.md) into this folder.
Use these exact file names so the README renders them automatically:

| File name             | Suggested page to capture                                  |
| --------------------- | ---------------------------------------------------------- |
| `home.png`            | The public home page (hero + main sections)                |
| `services.png`        | Supportive & palliative care services page                 |
| `news.png`            | News / blog listing or a single article                    |
| `donation.png`        | Online donation / campaign page                            |
| `courses.png`         | Courses (LMS) listing or a course detail page              |
| `dashboard.png`       | Admin dashboard (analytics / overview)                     |
| `page-builder.png`    | The component-based page builder in the dashboard          |
| `mobile.png`          | Any page on a mobile viewport (showcases responsive + RTL) |

**Tips**
- Export at ~1440px wide for desktop shots and ~390px wide for the mobile shot.
- PNG keeps text crisp; compress with [tinypng.com](https://tinypng.com) before committing.
- Because the UI is right-to-left (Persian), capture the full width so the layout reads correctly.
