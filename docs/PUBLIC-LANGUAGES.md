# زبان‌های بخش عمومی — مرحلهٔ اول

فارسی زبان پیش‌فرض است و آدرس‌های فعلی آن حفظ می‌شوند. زبان انگلیسی با `/en/` و عربی با `/ar/` مشخص می‌شود؛ برای نمونه `/home`، `/en/home` و `/ar/home`.
انتخاب‌گر زبان در هر دو نسخهٔ ناوبار مشترک (هدر داخلی و هدر صفحهٔ اصلی) قرار دارد و همان صفحه را در زبان انتخاب‌شده باز می‌کند.

## محدوده

- متن ثابت منو، فوتر، صفحات معرفی و خدمات، فرم‌ها، راهنماها و کنترل‌های نمایش ترجمه می‌شود.
- عنوان، توضیحات، تصویر و سایر داده‌های خبر، هیرو، کمپین، همکاران، شعب، دوره‌ها، رویدادها و روایات که از دیتابیس یا API می‌آیند تغییر نمی‌کنند.
- محتواهای ذخیره‌شدهٔ ویرایشگر در `data.json` دادهٔ مدیریت‌شده محسوب می‌شوند و در این مرحله ترجمه نمی‌شوند.
- متن داخل تصویر، پوستر، اسکن اساسنامه و PDF تغییر نمی‌کند.
- رابط داشبورد ادمین و پنل خیرین، حساب‌ها و آدرس‌های API چندزبانه نشده‌اند.
- این مرحله هیچ تغییری در ساختار یا داده‌های دیتابیس ندارد و به بیلد مجدد پنل React نیاز ندارد.

## ساختار پیاده‌سازی

- `public_html/core/locales/static.json`: عبارت ثابت فارسی و ترجمهٔ انگلیسی و عربی همان عبارت. ترجمه‌ها دستی هستند؛ سرویس ترجمهٔ آنلاین یا ترجمهٔ خودکار مرورگر استفاده نمی‌شود.
- `public_html/core/site-locale.php`: تعیین زبان از آدرس، ترجمه و escape متن ثابت، ساخت لینک زبان و انتخاب‌گر و ویژگی‌های سند.
- `public_html/localized.php`: اجرای مسیرهای مجاز بخش عمومی با همان صفحات و قالب‌های موجود. فایل دلخواه یا مسیر پنل را include نمی‌کند.
- `public_html/assets/site-locale.css` و `site-locale.js`: کنترل زبان، اصلاح چیدمان LTR و حفظ زبان لینک کارت‌هایی که پس از دریافت داده ساخته می‌شوند.
- `public_html/assets/site-navigation.css` و `site-navigation.js`: چیدمان و رفتار مشترک ناوبار صفحهٔ اصلی و هدر صفحات داخلی؛ جای‌گیری کنترل زبان، منوی حساب، زیرمنوها و منوی کشویی موبایل. منوی کامل با اندازهٔ واقعی متن و فضای موجود سنجیده می‌شود؛ وقتی جا کافی نباشد، منوی موبایل جایگزین می‌شود.

کنترل‌های ناوبار در گوشی حداقل ۴۴ پیکسل هستند. منوی موبایل اسکرول مستقل، کنترل فوکوس، خروج با Escape و بازگشت فوکوس دارد و در حالت بسته `inert` است. تغییر زبان آدرس همان صفحه، پارامترها و بخش انتخاب‌شدهٔ آدرس را حفظ می‌کند. لینک کارت‌های دارای `data-link` هم زبان انتخاب‌شده را حفظ می‌کنند.

متن ثابت قالب با `site_e('عبارت فارسی')` نمایش داده می‌شود. فقط عبارت ثابتِ نوشته‌شده در سورس به تابع ترجمه داده شود؛ مقادیری مانند `$news['title']`، نام همکار، محتوای خبر و پاسخ API نباید به آن داده شوند.
`site_js_text()` و `site_js_fragment()` همین جداسازی را برای برچسب‌های ثابت نوشته‌شده در JavaScript حفظ می‌کنند.
هیچ جایگزینی سراسری روی متن صفحه یا محتوای دریافتی انجام نمی‌شود؛ پردازش نهایی سند فقط زبان و جهت سند، لینک‌های داخلی و اطلاعات آدرس را تنظیم می‌کند.

زبان عربی RTL و انگلیسی LTR است. عدد و تاریخ محتوای دریافتی، واحد پول و منطق اعتبارسنجی فرم‌ها تغییر نکرده‌اند. سال‌های نوشته‌شده در متن ثابت به تقویم هجری شمسی اشاره می‌کنند و هنگام ترجمه به سال میلادی تبدیل نشده‌اند.
تا زمانی که نسخه‌های تحریریه‌ای محتوا تعریف نشده‌اند، خبرهای مختلف به‌عنوان ترجمهٔ یکدیگر با `hreflang` معرفی نمی‌شوند.

## بررسی

```powershell
.local/runtime/php/php.exe -n tests/site-locales.php
node tests/site-locales-browser.cjs
node tests/site-navigation-browser.cjs --pass=layout
node tests/site-navigation-browser.cjs --pass=interaction
node tests/local-stack.cjs
```

تست‌های مرورگر به Playwright نیاز دارند؛ با متغیر `PLAYWRIGHT_MODULE` می‌توان مسیر نصب موجود آن را مشخص کرد. مرورگر پیش‌فرض Chrome است و با `BROWSER_CHANNEL` قابل انتخاب است.
تست زبان‌ها مسیرهای هر سه زبان و JavaScript درون آن‌ها، کنترل زبان، چیدمان در اندازه‌های مختلف و حفظ عبارت‌های فارسی هیرو را بررسی می‌کند. تست قبلی نیز سلامت ورود و ثبت‌نام و صفحات فعلی را پوشش می‌دهد.

بررسی ناوبار دو دور مستقل دارد: دور چیدمان ۱۶۲ ترکیب صفحه/زبان/اندازه، ۱۳ عرض از ۳۲۰ تا ۱۹۲۰ پیکسل، قابل کلیک بودن تمام گزینه‌های زبان و دسترسی به انتهای زیرمنوها را بررسی می‌کند. دور تعامل، تغییر واقعی زبان در پروفایل‌های گوشی و دسکتاپ، اسکرول لمسی، چرخش و تغییر اندازه، فوکوس، حفظ آدرس و حساب کاربری با نام طولانی را پوشش می‌دهد. تصاویر بازبینی در `.local/nav-*.png` ذخیره می‌شوند و وارد گیت نمی‌شوند. شبیه‌سازی گوشی در Chrome جای آزمایش روی دستگاه واقعی و Safari را نمی‌گیرد.
