# اجرای کامل پروژه روی ویندوز

برای روشن کردن سایت روی **Start-Local.cmd** در ریشهٔ پروژه دوبار کلیک کنید.
پس از روشن شدن، سایت در مرورگر باز می‌شود.
برای خاموش کردن آن از **Stop-Local.cmd** استفاده کنید. این کار دیتابیس را پاک نمی‌کند.
پنجرهٔ وب‌سرور و دیتابیس در پس‌زمینه اجرا می‌شود؛ نیازی به باز نگه داشتن ترمینال نیست.

| بخش | آدرس |
| --- | --- |
| سایت | http://localhost:8080/home |
| پنل مدیریت | http://localhost:8080/dashboard/login.php |
| پنل خیرین React | http://localhost:8080/benefactor-dashboard/ |
| صندوق ایمیل آزمایشی | http://localhost:8025/ |

حساب‌های جداگانهٔ آزمایشی در فایل **`.local/access.txt`** نوشته شده‌اند:
نام کاربری مدیر `local-admin` و ایمیل خیر `local-donor@example.test` است.
رمز تصادفی داخل همان فایل است. اطلاعات ورود حساب‌های اکسپورت‌شده تغییر نمی‌کند.

## ابزارها

- Apache 2.4.69 با پشتیبانی از مسیرهای واقعی پروژه و قواعد `.htaccess`.
- PHP 8.4.26 نسخهٔ Thread Safe با افزونه‌های PDO MySQL، mysqli، mbstring، OpenSSL، cURL، fileinfo، GD، intl و ZIP.
- MariaDB 11.4.13، مطابق نسخهٔ دیتابیس اکسپورت‌شده.
- Mailpit 1.31.6 برای دریافت ایمیل‌های آزمایشی با SMTP و STARTTLS.
- Microsoft Visual C++ Runtime x64؛ روی سیستم فعلی موجود است.
- Node.js و npm برای تغییر و بیلد مجدد سورس React. برای اجرای بیلد موجود نیازی به اجرای Vite نیست.
- Composer برای اجرای فعلی لازم نیست؛ PHPMailer داخل پروژه وجود دارد.

ابزارهای قابل‌حمل در `.local/runtime` نصب شده‌اند؛ سرویس دائمی ویندوز نصب نمی‌شود.
همهٔ پورت‌ها فقط روی `127.0.0.1` گوش می‌دهند: وب 8080، دیتابیس 3306، SMTP 1025 و صندوق ایمیل 8025.

## دیتابیس و فایل‌ها

دیتابیس محلی **`macsa_local`** از اکسپورت SQL کاربر ساخته می‌شود.
این یک کپی مستقل است: تغییرات محلی به هاست ارسال نمی‌شوند و محتوای جدید هاست خودکار دریافت نمی‌شود.
فایل SQL بعد از ایمپورت، دیتابیس زنده نیست؛ داده‌های فعال در `.local/data` نگهداری می‌شوند.

تنظیمات، رمزها، داده‌های دیتابیس، ایمیل‌ها و گزارش‌ها داخل `.local` قرار دارند و در گیت ذخیره نمی‌شوند.
فایل نادیده‌گرفته‌شدهٔ `config/database.php` فقط اتصال قدیمی برخی صفحات را به تنظیمات محلی وصل می‌کند.
تنظیمات اصلی هاست و `.htaccess`های پروژه تغییر نمی‌کنند؛ هنگام شروع، قواعد مسیرها برای Apache محلی بازخوانی می‌شوند.
در خروجی PHP، لینک‌های داخلی `mymacsa.ir` به همین آدرس محلی تبدیل می‌شوند.

برای نصب اولیه روی سیستم دیگری، در PowerShell از ریشهٔ پروژه اجرا کنید:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/local.ps1 -Action setup -Dump "C:\path\to\export.sql"
```

این فرمان ابزارها را از منابع منتشرکننده دانلود و SHA256 بسته‌ها را بررسی می‌کند.
روی دیتابیس محلی دارای جدول، ایمپورت مجدد انجام نمی‌دهد و داده‌ها را بازنویسی نمی‌کند.
فقط دو تغییر تکرارپذیر و بررسی‌شدهٔ `014_campaign_service_donations.sql` و `021_rename_contact_center.sql` را برای هماهنگی با کد فعلی اعمال می‌کند؛ سایر migrationها خودکار اجرا نمی‌شوند.

وضعیت ابزارها:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/local.ps1 -Action status
```

فایل‌های تصویری و آپلودها از `public_html/uploads` و کامپوننت‌ها خوانده می‌شوند.
اگر فایلی فقط روی هاست موجود باشد، اکسپورت SQL خود آن فایل را در بر ندارد و باید آن را جداگانه به مسیر متناظر محلی کپی کنید.

## سرویس‌های بیرونی

ثبت‌نام و بازیابی رمز از SMTP واقعی برنامه استفاده می‌کنند، اما مقصد SMTP در این محیط Mailpit است؛
ایمیل‌ها در صندوق محلی دیده می‌شوند و به اشخاص واقعی فرستاده نمی‌شوند.
تأیید TLS خاموش نشده است؛ گواهی محلیِ SMTP به مخزن گواهی PHP همین محیط اضافه می‌شود.

درگاه پیش‌فرض API در حالت آزمایشی `stub` است؛ پرداخت بانکی واقعی انجام نمی‌شود.
کمپین‌های `/api/campaigns` و پنل خیرین از دیتابیس محلی خوانده می‌شوند.
اتصال قدیمی بعضی صفحات مالی به **Campaign Service** خارجی و ارسال پیامک واقعی، تنظیمات و کلیدهای همان سرویس‌ها را می‌خواهند؛ نصب وب‌سرور آن‌ها را ایجاد نمی‌کند.

## تست انجام‌شده

تست `tests/local-stack.cjs` با PHP و Playwright، ۶۸ مسیر شامل صفحات منتشرشده، شعب، خبر، خوراک‌های محتوا، API و مسیرهای React را بررسی می‌کند.
همچنین ورود مدیر، نشست، ورود خیر، داشبورد، سوابق کمک‌ها، اعلان‌ها، ثبت‌نام، دریافت SMTP و فعال‌سازی ایمیل را با دیتابیس محلی واقعی تست می‌کند.
این تست برای اجرای محلی است و به دیتابیس هاست متصل نمی‌شود.

منابع ابزارها: [Apache Lounge](https://www.apachelounge.com/download/)، [PHP Windows](https://windows.php.net/download/)، [MariaDB](https://dlm.mariadb.com/browse/mariadb_server/11.4.13/winx64-packages/)، [Mailpit](https://mailpit.axllent.org/docs/install/).
