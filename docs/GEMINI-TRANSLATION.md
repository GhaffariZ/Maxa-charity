# ترجمهٔ خودکار محتوای داشبورد

در تمام فرم‌های دارای تب عربی/انگلیسی، دکمهٔ «ترجمه و پرکردن از فارسی» جای گزینهٔ کپی قبلی را گرفته است. مدل ثابت این قابلیت `gemini-3.5-flash-lite` است؛ هیچ درخواستی به مدل TTS یا ساخت تصویر ارسال نمی‌شود.

## قرار دادن کلید روی هاست

در File Manager سی‌پنل، کنار پوشهٔ `public_html` پوشه‌ای به نام `maksa-private` بسازید یا همان پوشهٔ خصوصی موجود دیتابیس را باز کنید. فایل `gemini.php` را در آن قرار دهید:

```text
/home/CPANEL_USER/
  public_html/
  maksa-private/
    gemini.php
```

محتوای فایل:

```php
<?php
return [
    'api_key' => 'کلید واقعی Gemini را اینجا وارد کنید',
];
```

نام کاربری سی‌پنل خود را به‌جای `CPANEL_USER` در نظر بگیرید. فایل آمادهٔ بدون کلید در `docs/examples/gemini.php` قرار دارد؛ آن را به مسیر بالا کپی و مقدار خالی را تکمیل کنید. فایل واقعی را داخل `public_html`، دیتابیس، کد React، جاوااسکریپت یا گیت قرار ندهید. مسیر `maksa-private/` از قبل در گیت نادیده گرفته می‌شود. در هاست لینوکسی فایل را فقط برای کاربر اجرای PHP قابل خواندن نگه دارید؛ معمولاً مجوز `600` مناسب است.

در محیط محلی پروژه، همین فایل در `D:\Maxa-charity\maksa-private\gemini.php` قرار می‌گیرد. کد نمونه در ریشهٔ پروژه به‌تنهایی خوانده نمی‌شود؛ مسیر خصوصی بالا لازم است.

اگر سرور از تنظیم متغیر محیطی پشتیبانی می‌کند، می‌توانید به‌جای فایل، متغیر واقعی `GEMINI_API_KEY` را برای PHP تنظیم کنید؛ این متغیر بر فایل اولویت دارد. صرف نوشتن آن در یک فایل `.env` دلخواه کافی نیست.

کلید را از [Google AI Studio](https://aistudio.google.com/) بسازید و مطمئن شوید پروژه به مدل موردنظر دسترسی دارد. برای مصرف پولی، Billing و اعتبار همان پروژه باید فعال باشد. اشتراک Google AI Pro به‌تنهایی به معنی API نامحدود نیست.

## رفتار دکمه

- یک درخواست برای همهٔ متن‌های هر محتوا و زبان ارسال می‌شود. فقط بخش‌های عمومی موجود در فهرست ادیتور قابل ترجمه‌اند؛ تیکت، حساب کاربری و امور مالی وارد این مسیر نمی‌شوند.
- متن، عنوان‌ها، زیرنویس تصاویر و برچسب‌های دسترس‌پذیری ترجمه می‌شوند. کد HTML، CSS و JavaScript، نشانی‌ها، فایل‌ها، تاریخ‌ها و تنظیمات مشترک بازنویسی نمی‌شوند.
- عکس‌ها، ویدئوها، فایل‌های راهنما و محتوای داخل خود فایل PDF/تصویر به Gemini ارسال و ترجمه نمی‌شوند. فایل‌های فارسی هنگام ذخیره به نسخهٔ زبان کپی می‌شوند؛ می‌توانید در تب مقصد فایل مستقل انتخاب کنید.
- نتیجهٔ موفق فقط فرم را پر می‌کند؛ برای انتشار یا نگهداری باید فرم را ذخیره کنید. می‌توانید ترجمه را ویرایش کنید و با زدن مجدد دکمه از فارسی فعلی دوباره پر کنید.
- اگر محتوا در حین انتظار تغییر کند، پاسخ دیررس روی ویرایش جدید نوشته نمی‌شود. خطای سهمیه، تنظیم‌نبودن کلید، قطع ارتباط یا پاسخ ناقص هم محتوای قبلی را پاک نمی‌کند.

نتیجهٔ متن‌های یکسان تا ۲۴ ساعت از کش خصوصی استفاده می‌کند تا کلیک تکراری سهمیه را مصرف نکند. کش در `maksa-private/translation-cache` است و از وب قابل دریافت نیست؛ PHP برای کش باید اجازهٔ نوشتن در این پوشه را داشته باشد. اگر پوشه قابل نوشتن نباشد، ترجمه بدون کش انجام می‌شود. برای پاک‌کردن کش می‌توانید فایل‌های داخل همین پوشه را در زمان بیکاری ترجمه حذف کنید.

## نیازمندی و بررسی

PHP پروژه و افزونهٔ cURL با اتصال خروجی HTTPS به `generativelanguage.googleapis.com:443` کافی است. نیازی به نصب بستهٔ جدید Node یا Python روی هاست نیست. مسیر API کلید را فقط در هدر درخواست سرور به گوگل می‌فرستد و آن را در صفحه یا پاسخ خطا نمایش نمی‌دهد.

بعد از تنظیم کلید، یک متن کوتاه فارسی را در هیرو یا خبر وارد کنید، تب انگلیسی/عربی را باز و دکمه را بزنید. نتیجه و حفظ قالب، نام‌ها، اعداد و اصطلاحات را بررسی کنید، سپس فرم را ذخیره کنید. محدودیت واقعی مدل و موجودی در [Google AI Studio](https://aistudio.google.com/) دیده می‌شود.

آزمون‌های خودکار بدون تماس واقعی با گوگل:

```powershell
& .local/runtime/php/php.exe -c .local/conf/php.ini tests/content-translation.php
node tests/content-translation-browser.cjs
node tests/content-locales-browser.cjs
node tests/content-editor-layout.cjs
```
