# دیتابیس (Database)

این پوشه ساختار و بک‌آپ دیتابیس سایت MACSA را نگه می‌دارد تا با گیت نسخه‌بندی شود و
هنگام دیپلوی سی‌پنل، روی دیتابیس production اعمال شود.

## فایل‌ها

| فایل | توضیح | داخل گیت؟ |
|------|-------|-----------|
| `schema.sql` | بک‌آپ کامل دیتابیس (ساختار + دیتای تستی) | ✅ بله |
| `import.sh` | اسکریپتی که موقع دیپلوی، `schema.sql` را روی دیتابیس import می‌کند | ✅ بله |
| `db.conf.example` | نمونه‌ی فایل اطلاعات اتصال دیتابیس | ✅ بله |
| `db.conf` | اطلاعات واقعی اتصال (فقط روی سرور) | ❌ خیر (gitignore) |

---

## ⚠️ هشدار مهم

اسکریپت import **کل دیتابیس را با محتوای `schema.sql` بازنویسی می‌کند**.

این کار **فقط در مرحله‌ی تست** که هیچ دیتای واقعی‌ای وجود ندارد امن است.
**به‌محض اینکه سایت کاربر و دیتای واقعی (دونیشن، اطلاعات بیمار و...) پیدا کرد،**
این روش را کنار بگذار و سراغ سیستم **migration** برو (پایین توضیح داده شده) —
وگرنه هر دیپلوی، دیتای واقعی کاربرها را پاک می‌کند.

---

## راه‌اندازی اولیه (یک‌بار روی سرور)

۱. وارد سی‌پنل شو → **MySQL Databases** و اطلاعات دیتابیس را بردار.

۲. فایل `db.conf` را کنار `import.sh` روی سرور بساز (در مسیر `database/db.conf`):

```bash
cp database/db.conf.example database/db.conf
nano database/db.conf   # مقادیر واقعی را پر کن
```

> این فایل gitignore شده، پس هیچ‌وقت کامیت نمی‌شود و پسورد لو نمی‌رود.

از این به بعد هر دیپلوی، به‌صورت خودکار `schema.sql` را روی دیتابیس import می‌کند.

## گردش کار روزمره (Workflow)

### وقتی ساختار دیتابیس را تغییر دادی (جدول/ستون جدید و...)

۱. **export گرفتن از دیتابیس** (دو روش — یکی را انتخاب کن):

   **روش الف) phpMyAdmin** (ساده‌تر):
   - وارد phpMyAdmin شو و دیتابیس `erfantey_macsacharity` را انتخاب کن.
   - تب **Export** → حالت **Custom**.
   - فرمت: **SQL**.
   - گزینه‌ی **"Add DROP TABLE / VIEW / ... statement"** را تیک بزن
     (تا موقع import، جدول‌های قدیمی drop و دوباره ساخته شوند).
   - **Go** → فایل دانلودی را با نام `schema.sql` داخل همین پوشه (`database/`) جایگزین کن.

   **روش ب) خط فرمان** (روی سرور یا لوکال):
   ```bash
   mysqldump --host=localhost \
             --user=erfantey_fantasticfour \
             --password \
             --add-drop-table \
             erfantey_macsacharity > database/schema.sql
   ```

۲. **کامیت و push:**
   ```bash
   git add database/schema.sql
   git commit -m "db: update schema"
   git push
   ```

۳. **دیپلوی در سی‌پنل** (Git Version Control → Deploy HEAD Commit).
   سی‌پنل فایل‌ها را کپی و سپس `import.sh` را اجرا می‌کند و دیتابیس آپدیت می‌شود.

## مسیر آینده: مهاجرت به سیستم Migration

وقتی سایت واقعی شد، به‌جای بازنویسی کل دیتابیس، تغییرات را به‌صورت فایل‌های جداگانه
و افزایشی نگه‌دار (مثلاً پوشه‌ی `database/migrations/` با فایل‌هایی مثل
`001_create_pages.sql`، `002_add_views_to_news.sql`). اسکریپت دیپلوی فقط
migrationهای اجرانشده را اجرا می‌کند و دیتای موجود دست‌نخورده می‌ماند.
